# Tilphee Portfolio — Homepage Foundation

A premium, responsive Next.js starter for Tilphee, the personal brand of Boluwatife Dorcas Oladapo, Certified AI Automation Specialist.

## Stack
- Next.js App Router
- React + TypeScript
- Custom CSS design system

## Run locally
1. Install Node.js 20.9+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open `http://localhost:3000`.

## Current build
- Responsive homepage with navigation and footer
- Premium navy / champagne / warm-white design system
- Hero workflow illustration built in CSS (no stock robot artwork)
- Real-estate specialization, broader industry positioning, services preview, featured projects, approach preview and CTA
- Basic page metadata and Open Graph defaults
